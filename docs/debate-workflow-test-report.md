## 2. 2차 코드 리뷰 반영 사항

### 2-1. 참여자 명단 확정

- 임원진의 참여자 확정 기능 추가.
- 승인된 참여자 4명 이상일 때만 확정 가능.
- 확정 전 참여자 추가 및 삭제 가능.
- 확정 후 참여자 명단 변경 차단.
- 확정 전 사전 의견 제출 차단.
- 확정 이후 승인된 참여자가 4명 미만이 되면 사전 의견 제출 및 토론 시작 차단.

### 2-2. 탈퇴 참여자 처리

- 탈퇴 처리된 참여자를 진행 중인 토론의 유효 인원 집계에서 제외.
- 기존 제출 기록 자체는 삭제하지 않음.
- 승인 상태 복구 시 유효 참여자로 다시 집계.
- 종료된 토론의 통계 및 MVP 득표수는 스냅샷으로 보존.
- 탈퇴 처리와 계정 완전 삭제는 구분하며 완전 삭제 관련 추가 검증 필요.

### 2-3. 조회 및 폴링 개선

- 토론 상세 화면의 경량 상태 조회 도입.
- 상태 변경 시 전체 데이터 조회.
- 주기적인 전체 조회 보완 방식 유지.
- 종료된 토론 상세 화면의 반복 폴링 중단.
- 비활성 브라우저 탭의 폴링 중단 및 복귀 시 갱신.
- 토론 목록에서도 경량 상태 조회 적용.
- 실제 대규모 동시 접속 부하 시험은 미실시.

### 2-4. 모바일 CSS 개선

- 찬반 선택 상자와 MVP 후보 행의 CSS 충돌 수정.
- 360px 환경에서 찬반 선택 및 MVP 화면 확인.
- MVP 후보 이름, 선택 버튼 및 배치 확인.
- 좁은 화면에서 일부 콘텐츠가 잘려 보이는 현상은 추가 개선 필요.
- 전체 모바일 화면에 대한 완전한 검증으로 판단하지 않음.

### 2-5. 최신 main 반영

- main 커밋 5b1cf15 병합.
- INDEX.md 충돌 해결.
- SQL 37번 운영 적용 완료 상태 유지.
